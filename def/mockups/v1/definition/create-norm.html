Selected on the previous step. A Norm is a governance primitive, not a subject type — it operationalizes a parent Directive into a measurable assertion over a governed Structure, evaluated as a CEL expression under a tolerance mode. Each field below carries its schema properties and metadata.

Statement
gsm/Norm/v1 — identity & scope

uuid required identity-bound Viability dimension being measured — the qualifier archetype this norm asserts against.
gsm/Norm/v1 — CEL grammar & tolerance
Instantaneous
Any single assertion failure = violation. No temporal window.
Aggregated
Measured over a temporal window using an aggregation function.
Sustained
Must hold for a threshold proportion within a temporal window.
