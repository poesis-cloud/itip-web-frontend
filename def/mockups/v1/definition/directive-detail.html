Governed Structure ExternalEndpoints
API Gateway MUST ENFORCE rate limiting and authentication ON ExternalEndpoints
All externally facing API endpoints must pass through the API Gateway, which enforces rate limiting (max 1000 req/min per API key) and OAuth2/OIDC authentication before forwarding to internal microservices. This fulfills NIS2 Art.21 §2(a) risk management measures for network security.

ℹ About CEL Expressions
Norms use Common Expression Language (CEL) to define machine-evaluable assertions. Each norm has an applicability condition (WHEN) and an assertion (ASSERT) that the governed structure must satisfy. The governance-assertion CEL profile provides access to the subject’s properties, state, and ascription metadata.
