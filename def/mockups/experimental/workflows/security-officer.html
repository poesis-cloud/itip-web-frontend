Workflow: Framework Stack Composition & Regulatory Coverage Audit

🛡 Security Officer

End-to-end workflow for composing a governance framework stack and auditing regulatory coverage across the architecture.

1

Browse Framework Catalog

Security Officer opens the Framework Catalog to review available sourced frameworks (TOGAF, NIS2, GDPR, ISO 25010, SCAP).

2

Compose Framework Stack

Select and combine relevant frameworks into a stack. The Stack Composer shows overlap analysis and identifies directive conflicts across frameworks.

📄 Screen: Stack Composer

3

Resolve Conflicts & Gaps

For each detected conflict, choose the stricter norm or merge requirements. Copilot Assist suggests resolutions based on regulatory precedence.

Decision: Conflict resolution strategy?
✓ Stricter wins — use NIS2's encryption requirement (AES-256) which subsumes SCAP baseline
✗ Split norms — keep both with different applicability scopes
4

Run Regulatory Coverage Audit

Trigger a full evaluation that maps all active structures against the composed framework stack, producing a coverage report.

📄 Screen: Adherence Matrix
┌──────────────────────────────────┐ │ Regulatory Coverage Audit │ ├──────────────────────────────────┤ │ Coverage Gaps Found: 3 │ │ │ │ ❌ PaymentService │ │ Missing: GDPR data retention │ │ Missing: NIS2 access control │ │ │ │ ❌ LegacyAuthBridge │ │ Missing: SCAP vulnerability │ │ scan (deprecated; schedule │ │ retirement) │ │ │ │ ⚠ CustomerDataFlow │ │ Partial: ISO25010 security │ │ (encryption in transit only) │ │ │ │ [Generate Gap Report] │ │ [Create Remediation Directives] │ └──────────────────────────────────┘
5

Generate Remediation Directives

For each coverage gap, create draft directives and norms. Copilot Assist pre-fills the governance grammar from the sourced framework text.

📄 Screen: Governance Authoring
Decision: Submit for review or save as draft?
✓ Submit — new directives go to Enterprise Architect for approval
✗ Draft — save for further refinement during next governance cycle
6

Monitor & Report

Return to the Dashboard to monitor stack coverage over time. Export compliance reports for regulatory bodies or management review.
