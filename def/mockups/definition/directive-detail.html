ℹ About CEL Expressions
Norms use Common Expression Language (CEL) to define machine-evaluable assertions. Each norm has an applicability condition (WHEN) and an assertion (ASSERT) that the governed structure must satisfy. The governance-assertion CEL profile provides access to the subject’s properties, state, and ascription metadata.
